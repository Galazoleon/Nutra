# Nutra product brief (condensed from the owner's master prompt)

The owner's full master prompt was pasted into a Claude Code session on 2026-11-08. This is a faithful
summary of its requirements. If you have the original file, save it next to this one as `MASTER_PROMPT.md`.

## Product
- Educational nutrition and fitness iPhone app. SwiftUI, Swift 6 strict concurrency, iOS 17+, iPhone only,
  no third-party packages. Project `NutraNutritionCoach`, generated by XcodeGen from `project.yml`.
- A web prototype (`docs/reference-prototype/index.html`) is the source of truth for behavior and copy
  (not yet in the repo). Spec authority: Part 4 > Part 3 > Part 2 > Part 1; prototype beats prose.
- Logging by photo, voice or text → one review screen: calories, protein, carbs, fat, fiber, glycemic index
  and load, % daily value for ten micronutrients, confidence pill, portion steppers, A-Z add list, allergen
  and fried heads-up, two-sentence insight, Save/Discard.
- Food data: 58 starter foods, plus 738 dishes from 197 countries (35 nutrients each). Estimates, not USDA-verified.
- 37 goals; a pure, tested TargetsEngine turns goal + person into starting numbers.
- Tabs: Dashboard, Log (emphasized), Coach, Profile. Dashboard = goal-specific modules via a ModuleRegistry;
  every goal has a distinct dashboard in gentle and standard mode.
- Coach: Plan, Meals (planner; Pro: 7-day plan, shopping list, batch prep, swaps), Foods (custom foods,
  label/barcode scanning, Suggest-to-Nutra), Ask (14-question rule-based preview, 3 free, live backend path),
  Diets, Cuisines, Countries, Allergy, Train (2-6 day plans for gym/dumbbells/bodyweight + injury coach).
- Layered onboarding with Step N of M, Back/Continue/Skip, resume, neutral Pro page, summary, Redo setup.
  Age 5-17 = under-18, 18+ = adult.
- Free vs Pro through one entitlements layer, StoreKit 2 (demo toggle until products exist). Locked actions
  open the paywall, never fail silently.
- Profile: Health data (HealthKit, labeled sample fallback), household, plan, about you, goals, food dictionary,
  redo setup, real export, real delete with confirmation, opt-in reminders.
- User foods always labeled "Your food, not verified". Parser includes user foods; unknown phrases become
  "Not in Nutra's foods yet" chips.

## Hard rules
- No weight-change goals or calorie numbers for under-18 or pregnant. Floors 1,200 female / 1,500 male or
  unspecified. No rapid cuts. 14-day trend rule. Gentle mode hides numbers at the view-model level with a
  banned-token test. Safety notices for under-18, pregnancy, combat sports. Injury coach uses the
  "3 out of 10 pain" rule and never diagnoses.
- No red. No streak pressure, shame or penalties. Amber for caution, indigo for emphasis. Full dark mode.
- "Educational, not medical advice" and "estimate" labels everywhere; disclaimers in one constants file.
- Never an AI key in the app; Supabase functions hold keys. Content is JSON data; validated at launch in debug.
- Pure logic lives in the Swift package so tests run fast. World dish data loads off the main thread.
- Accessibility: VoiceOver labels, Dynamic Type, contrast, reduced motion, 44 pt targets.
- Stubs are real code paths with `// NEEDS:` markers.
- Mulberry32 must match the prototype exactly so plans are reproducible from a seed.

## Out of scope for now
- Diet styles beyond Mediterranean, Carnivore, Pescatarian, Vegetarian. Faith-based filters.
- Apple Watch, widgets, Android, iPad layouts, extra localization, real payments, live server, App Store submission.
