# Nutra status

_Last updated: 2026-11-08_

## Important honesty notes
- **This code has not been compiled yet.** It was written in a cloud workspace (Linux) that has no Swift
  compiler and no Xcode. It was reviewed carefully by hand, and the meal planner and Mulberry32 maths were
  checked by running the same algorithm in Python. The first real build happens on your Mac.
- The reference prototype (`docs/reference-prototype/index.html`), the Part 1-4 specs, the 30 pieces file and the
  original data files were **not in the repository**, so this version was built from the master prompt's
  description. When those files are added, the planner (Part 4), trend rule (Part 3) and copy should be
  compared against them. Places to reconcile are marked `NOTE: reconcile`.
- Nutrition values, targets, recipes, workouts and injury guidance are estimates and **need review by a
  registered dietitian and a qualified trainer or physiotherapist** before real people rely on them.
